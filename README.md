# Вектор — AI-ассистент для маркетологов

Рабочее место маркетолога: AI-чат по 16 направлениям маркетинга, to do list и калькулятор маркетинговых метрик.

**Сайт:** https://vektor-ai-marketing.vercel.app (проект Vercel `vektor`; старый адрес marketing-pilot-five.vercel.app тоже работает)
**Код:** https://github.com/alexlojkov-code/vektor

- [PRD.md](PRD.md) — продуктовые требования: проблема, аудитория, направления, функции, метрики успеха.
- [SPEC.md](SPEC.md) — техническая спецификация: архитектура, API, формулы, экраны, дизайн-система, критерии приёмки.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000: лендинг — `/`, приложение — `/app.html`.

## AI-ключ

Как в Eatlas: общий ключ сервиса лежит только в переменной окружения на Vercel и никогда не попадает в браузер. Браузер обращается к `/api/chat`, сервер добавляет ключ и пересылает запрос в OpenAI.

Подключить ключ OpenAI:

```bash
vercel env add OPENAI_API_KEY production --sensitive
vercel deploy --prod
```

Провайдер выбирается по заданному ключу (`OPENAI_API_KEY` → OpenAI, `ANTHROPIC_API_KEY` → Claude); можно указать явно в `AI_PROVIDER`. Модель по умолчанию — `gpt-5.4-mini`; если она перегружена (429/5xx), недоступна ключу (404) или молчит в потоке, сервер сразу пробует запасные (`gpt-5.4-nano`, `gpt-5.4`) и откладывает занятую модель на 3 минуты. Список меняется переменными `AI_MODEL` и `AI_FALLBACK_MODELS`. Подойдёт и другой OpenAI-совместимый сервис — адрес задаётся в `OPENAI_BASE_URL`.

Дневные лимиты (сутки по UTC): вошедший пользователь — `AI_DAILY_LIMIT_USER` (50), гость по хэшу IP — `AI_DAILY_LIMIT_GUEST` (15), весь сервис — `AI_DAILY_LIMIT_TOTAL` (1500). Неудачные запросы лимит не расходуют. Счётчики — в Upstash Redis (без него — в памяти экземпляра функции, это слабее). Дополнительно поставьте лимит расходов в кабинете OpenAI.

Локально (`.env`, пример — `.env.example`):

| Настройка | Что происходит |
|---|---|
| `OPENAI_API_KEY` | Настоящие ответы OpenAI потоком |
| Ключа нет или `AI_PROVIDER=none` | AI выключен, задачи и калькулятор работают |
| `AI_PROVIDER=mock` | Демо-режим: шаблонные ответы без сети и без лимитов |

## Аккаунты и синхронизация

Без настроек приложение работает как раньше: данные только в браузере, кнопки входа нет. Чтобы включить аккаунты на Vercel:

1. Проект `vektor` → **Storage** → **Upstash for Redis** (бесплатный тариф) → **Connect** к проекту.
2. Переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` появятся сами — пересоберите проект (Deployments → Redeploy).

Вход — по почте и паролю. Писем сервис не отправляет: при регистрации показывается код восстановления, по нему можно задать новый пароль. Локально аккаунты включаются `DB_PROVIDER=memory` (данные живут до перезапуска сервера).

## Валюта

Калькулятор считает в сумах или долларах — переключатель в шапке калькулятора. Курс не пересчитывается: вводятся свои числа.

## Установка на телефон (PWA)

«Вектор» можно установить как приложение: в Chrome и на Android — кнопкой «Установить приложение» в меню или с плашки на экране «Сегодня», на iPhone — «Поделиться → На экран „Домой“» (в приложении есть подсказка). Без интернета работают задачи, калькулятор, профиль бренда и прошлые чаты.

Файлы: `public/manifest.webmanifest`, `public/sw.js` (кэш «сначала сеть»), `public/js/pwa.js`. Если меняете список файлов оболочки в `sw.js`, поднимите версию `CACHE`.

## Превью ссылки

`public/og.png` (1200×630), `public/apple-touch-icon.png` и иконки приложения `public/icons/` собираются из `scripts/og-image.mjs`:

```bash
npm run build:og
```

## 3D-объекты лендинга

Исходник — `src/scene3d.js` (Three.js). После правок пересоберите бандл:

```bash
npm run build:3d
```

Готовый файл `public/js/scene3d.min.js` хранится в репозитории, на Vercel сборка не нужна.

## Liquid Glass

Эффект стекла — отдельный слой: `public/css/liquid-glass.css` и `public/js/liquid-glass.js`, включается атрибутом `data-glass` на `<html>` в `index.html` и `app.html`. Чтобы убрать эффект, удалите атрибут `data-glass` (или подключения этих двух файлов) в обоих HTML-файлах.

## Тесты

```bash
npm test
```

Проверяют все формулы калькулятора, воронку, валюту, разбор чисел, поиск метрик и слияние данных двух устройств.

## Структура

```
api/            функции Vercel: /api/chat (поток NDJSON), /api/ai/status, /api/account, /api/sync
api/_lib/       конфигурация, промпты, AI-провайдеры (OpenAI, Anthropic, демо), дневные лимиты, хранилище (Redis), аккаунты
public/         лендинг и приложение (чистые HTML/CSS/JS, без сборки)
src/            исходник 3D-сцены (собирается в public/js/scene3d.min.js)
scripts/        локальный сервер, генерация картинки превью
tests/          тесты формул, валюты, синхронизации, провайдера OpenAI и лимитов
```
