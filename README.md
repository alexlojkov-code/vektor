# Вектор — AI-ассистент для маркетологов

Рабочее место маркетолога: AI-чат по 16 направлениям маркетинга, to do list и калькулятор маркетинговых метрик.

**Сайт:** https://vektor-ai-marketing.vercel.app (проект Vercel `vektor`; старый адрес marketing-pilot-five.vercel.app переадресует сюда)
**Код:** https://github.com/alexlojkov-code/vektor

- [PRD.md](PRD.md) — продуктовые требования: проблема, аудитория, направления, функции, метрики успеха.
- [SPEC.md](SPEC.md) — техническая спецификация: архитектура, API, формулы, экраны, дизайн-система, критерии приёмки.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000: лендинг — `/`, приложение — `/app.html`.

## AI-ключ

Как в Eatlas: общий ключ сервиса лежит только в переменной окружения на Vercel и никогда не попадает в браузер. Браузер обращается к `/api/chat`, сервер добавляет ключ и пересылает запрос в Gemini (через его OpenAI-совместимый адрес `generativelanguage.googleapis.com/v1beta/openai`).

Подключить ключ Gemini (aistudio.google.com → Get API key):

```bash
vercel env add GEMINI_API_KEY production --sensitive
vercel deploy --prod
```

Провайдер выбирается по заданному ключу: `GEMINI_API_KEY` → Gemini, `OPENAI_API_KEY` → OpenAI, `ANTHROPIC_API_KEY` → Claude; можно указать явно в `AI_PROVIDER`.

Модели на выбор — список под заголовком чата, выбор запоминается и синхронизируется:

| Модель | В списке |
|---|---|
| `gemini-3.8-flash` (по умолчанию) | Gemini 3.8 Flash — точнее |
| `gemini-3.6-flash` | Gemini 3.6 Flash — баланс |
| `gemini-3.5-flash-lite` | Gemini 3.5 Flash-Lite — быстрее |

Если выбранная модель перегружена (429/5xx), недоступна ключу или тарифу (404, «limit: 0»), или молчит в потоке, сервер сразу пробует остальные из списка. Список меняется переменными `AI_MODEL` и `AI_FALLBACK_MODELS`.

Дневные лимиты (сутки по UTC): вошедший пользователь — `AI_DAILY_LIMIT_USER` (50), гость по хэшу IP — `AI_DAILY_LIMIT_GUEST` (15), весь сервис — `AI_DAILY_LIMIT_TOTAL` (1500). Неудачные запросы лимит не расходуют. Счётчики — в Upstash Redis (без него — в памяти экземпляра функции, это слабее).

Локально (`.env`, пример — `.env.example`):

| Настройка | Что происходит |
|---|---|
| `GEMINI_API_KEY` (или `OPENAI_API_KEY`) | Настоящие ответы потоком |
| Ключа нет или `AI_PROVIDER=none` | AI выключен, задачи и калькулятор работают |
| `AI_PROVIDER=mock` | Демо-режим: шаблонные ответы без сети и без лимитов |

## Аккаунты и синхронизация

Без настроек приложение работает как раньше: данные только в браузере, кнопки входа нет. Чтобы включить аккаунты на Vercel:

1. Проект `vektor` → **Storage** → **Upstash for Redis** (бесплатный тариф) → **Connect** к проекту.
2. Переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` появятся сами — пересоберите проект (Deployments → Redeploy).

Вход — по почте и паролю. Писем сервис не отправляет: при регистрации показывается код восстановления, по нему можно задать новый пароль. Локально аккаунты включаются `DB_PROVIDER=memory` (данные живут до перезапуска сервера).

## Валюта

Калькулятор считает в сумах или долларах — переключатель в шапке калькулятора. Курс не пересчитывается: вводятся свои числа.

## Установка на телефон (PWA)

«Вектор» можно установить как приложение: в Chrome и на Android — кнопкой «Установить приложение» в меню или с плашки на экране «Сегодня», на iPhone — «Поделиться → На экран „Домой“» (в приложении есть подсказка). Без интернета работают задачи, калькулятор, профиль бренда и прошлые чаты.

Файлы: `public/manifest.webmanifest`, `public/sw.js` (кэш «сначала сеть»), `public/js/pwa.js`. Если меняете список файлов оболочки в `sw.js`, поднимите версию `CACHE`.

## Превью ссылки

`public/og.png` (1200×630), `public/apple-touch-icon.png` и иконки приложения `public/icons/` собираются из `scripts/og-image.mjs`:

```bash
npm run build:og
```

## 3D-объекты лендинга

Исходник — `src/scene3d.js` (Three.js). После правок пересоберите бандл:

```bash
npm run build:3d
```

Готовый файл `public/js/scene3d.min.js` хранится в репозитории, на Vercel сборка не нужна.

## Liquid Glass

Эффект стекла — отдельный слой: `public/css/liquid-glass.css` и `public/js/liquid-glass.js`, включается атрибутом `data-glass` на `<html>` в `index.html` и `app.html`. Чтобы убрать эффект, удалите атрибут `data-glass` (или подключения этих двух файлов) в обоих HTML-файлах.

## Тесты

```bash
npm test
```

Проверяют все формулы калькулятора, воронку, валюту, разбор чисел, поиск метрик и слияние данных двух устройств.

### Сквозные проверки в браузере

Сценарии кликают по сайту как человек, в WebKit — движке Safari, с экраном iPhone 13:

- `tests/e2e/screens.mjs` — быстрый обход всех экранов на телефоне, планшете и компьютере в тёмной и светлой теме: ничего не вылезает за край, текст читается (контраст с фоном не ниже 3:1, у градиента — с худшим цветом). Без аккаунта и AI, отдельно: `npm run test:e2e:screens`;
- `tests/e2e/main.mjs` — лендинг, «Сегодня», профиль бренда, меню, калькулятор, задачи, регистрация, AI-чат, «В задачи», выход и вход, тема, политика;
- `tests/e2e/extra.mjs` — экраны компьютера и планшета, светлая тема, «Стоп» и «Повторить», таблица в ответе, длинные данные и XSS, два устройства одновременно, ошибки входа, сброс пароля, работа без интернета.

```bash
npx playwright install webkit
npm run test:e2e
```

По умолчанию проверяется боевой сайт; другой адрес — через `E2E_URL=http://localhost:3000 npm run test:e2e`. Каждый набор создаёт тестовый аккаунт `qa…@vektor.test` и удаляет его в конце, тратит 1–3 запроса к AI. Снимки экранов — в `tests/e2e/out/` (в git не попадают).

## Структура

```
api/            функции Vercel: /api/chat (поток NDJSON), /api/ai/status, /api/account, /api/sync
api/_lib/       конфигурация, промпты, AI-провайдеры (Gemini и OpenAI, Anthropic, демо), дневные лимиты, хранилище (Redis), аккаунты
public/         лендинг и приложение (чистые HTML/CSS/JS, без сборки)
src/            исходник 3D-сцены (собирается в public/js/scene3d.min.js)
scripts/        локальный сервер, генерация картинки превью
tests/          тесты формул, валюты, синхронизации, провайдера Gemini/OpenAI и лимитов
```
