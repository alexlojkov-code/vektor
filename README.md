# Вектор — AI-ассистент для маркетологов

Рабочее место маркетолога: AI-чат по 16 направлениям маркетинга, to do list и калькулятор маркетинговых метрик.

**Сайт:** https://marketing-pilot-five.vercel.app (проект Vercel `marketing-pilot`)
**Код:** https://github.com/alexlojkov-code/vektor (приватный репозиторий)

- [PRD.md](PRD.md) — продуктовые требования: проблема, аудитория, направления, функции, метрики успеха.
- [SPEC.md](SPEC.md) — техническая спецификация: архитектура, API, формулы, экраны, дизайн-система, критерии приёмки.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000: лендинг — `/`, приложение — `/app.html`.

Режим AI задаётся в `.env` (пример — `.env.example`):

| `AI_PROVIDER` | Что происходит |
|---|---|
| `anthropic` + `ANTHROPIC_API_KEY` | Настоящие ответы Claude (`claude-opus-5-5`, потоком) |
| `anthropic` без ключа или `none` | AI выключен, задачи и калькулятор работают |
| `mock` | Демо-режим: шаблонные ответы без сети |

## 3D-объекты лендинга

Исходник — `src/scene3d.js` (Three.js). После правок пересоберите бандл:

```bash
npm run build:3d
```

Готовый файл `public/js/scene3d.min.js` хранится в репозитории, на Vercel сборка не нужна.

## Liquid Glass

Эффект стекла — отдельный слой: `public/css/liquid-glass.css` и `public/js/liquid-glass.js`, включается атрибутом `data-glass` на `<html>` в `index.html` и `app.html`. Чтобы убрать эффект, удалите атрибут `data-glass` (или подключения этих двух файлов) в обоих HTML-файлах.

## Тесты

```bash
npm test
```

Проверяют все формулы калькулятора, воронку, разбор чисел и поиск метрик.

## Структура

```
api/            функции Vercel: /api/chat (поток NDJSON), /api/ai/status
api/_lib/       конфигурация, промпты направлений, AI-провайдеры
public/         лендинг и приложение (чистые HTML/CSS/JS, без сборки)
tests/          тесты формул
```

## Деплой

`vercel` из папки проекта; в настройках проекта задайте переменные из `.env.example`.
